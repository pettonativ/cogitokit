# MKTG-KIT (Marketing Kit)

> Core extension for Personal Branding, LinkedIn Content Management, and Search Engine Optimization.
> Designed as a submodule for `cogitokit`.

## 🤖 Agents

- **`linkedin-specialist`**: Content writer and brand strategist for LinkedIn.

## 🛠️ Skills

- **`linkedin-content`**: Implementation of HOAI (James Gray) LinkedIn writing principles.
- **`seo-specialist`**: Core SEO fundamentals and optimization strategies.

## 🚀 Usage

This kit is designed to be used within the `antigravity` workflow via `cogitokit`.
Keywords to trigger: `linkedin`, `personal branding`, `seo report`, `scrivere post`.
