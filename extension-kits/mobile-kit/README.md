# Mobile Kit

> **Add-on kit** for the [cogitokit](https://github.com/pettonativ/cogitokit) multi-kit AI agent system.

Provides **Mobile Development** skills — Mobile Design Patterns, React Native, Flutter, iOS, Android.

---

## 🎯 Purpose

A dedicated ecosystem for building native or cross-platform mobile apps:

| Skill               | Focus                                        | Status      |
| ------------------- | -------------------------------------------- | ----------- |
| **`mobile-design`** | Touch psychology, layouts, mobile typography | ✅ Complete |

---

## 🏗️ Architecture

```
mobile-kit/
├── .agent/
│   ├── ARCHITECTURE.md
│   ├── agents/
│   │   └── mobile-developer.md
│   └── skills/
│       └── mobile-design/
└── README.md
```

---

## 🔌 How to Use

1. **Included as submodule** of `cogitokit` under `extension-kits/mobile-kit/`
2. Antigravity **auto-discovers** all skills when the workspace is open
3. Route queries related to app development, Swift, Kotlin, React Native, and mobile UI to the `mobile-developer`.
