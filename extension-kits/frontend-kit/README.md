# Frontend Kit

> **Add-on kit** for the [cogitokit](https://github.com/pettonativ/cogitokit) multi-kit AI agent system.

Provides **Web UI/UX and Frontend Framework** skills — Next.js, React, Tailwind CSS, Web Design Guidelines.

---

## 🎯 Purpose

A dedicated ecosystem for building, designing, and optimizing Web UIs:

| Skill                     | Focus                                                 | Status      |
| ------------------------- | ----------------------------------------------------- | ----------- |
| **`frontend-design`**     | UX Psychology, Web Animations, Interface aesthetics   | ✅ Complete |
| **`nextjs-react-expert`** | Modern React, Next.js optimization, Server Components | ✅ Complete |
| **`tailwind-patterns`**   | Tailwind v4, container queries, modern styling        | ✅ Complete |

---

---

## 🔌 How to Use

1. **Included as submodule** of `cogitokit` under `extension-kits/frontend-kit/`
2. Antigravity **auto-discovers** all skills when the workspace is open
3. Route queries related to visual design, React, and Tailwind to the `frontend-specialist`.
